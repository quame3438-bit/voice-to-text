语音转文字

适合 iPhone / iPad。选择录音文件后上传到你的云端转写接口，返回文字后可直接复制或导出 TXT。
支持：m4a / mp3 / wav / mp4 / aac / flac
请选择一个语音文件。

接口设置
GitHub Pages 只是网页前端，不能安全保存转写服务的 API 密钥。 请把你的 Supabase Edge Function 或其他转写后端地址填在下面。地址会只保存在当前设备浏览器中。
接口返回格式
网页会以 multipart/form-data 发送：file、language、mode。
接口返回 JSON：{"text":"识别出来的文字"}。
